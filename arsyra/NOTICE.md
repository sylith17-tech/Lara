# ArSyra Arabic Dialogue Integration

This project includes the dataset:

- Name: Arabic Dialogues 5K
- Source: https://huggingface.co/datasets/tahaalselwii/arabic-dialogues-5k
- Author/Publisher: tahaalselwii
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)

The dataset is used locally by the ArSyra dialogue engine as a conversational
fallback for Lara.
